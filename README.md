# GUI Basketball Games Display with Rust
- The (hopefully) final installment in the basketball stats viewer saga, preceded by the gui_basketball and bball_stats projects.
- Made using ratatui for a rich terminal based experience
- Uses the balldontlie api to get NBA games happening today and display them with theirs core on the screen.

## Cloning
### Prerequsites - Rust
- `git clone https://github.com/Shaven-Wickramanayaka/tui_basketball.git`
- `cd tui_basketball`
- `cargo run`
